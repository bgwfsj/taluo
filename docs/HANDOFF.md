# 塔罗之语 · 交接文档

当前版本：v0.1.0（2026-11-18）

## 一句话
清爽简约的纯前端塔罗牌 App：每日一抽 + 六维解读、78 张牌正/逆位图鉴、
已学习标记、每牌无限条备注（每条 ≤500 字）。数据全部存本地 localStorage，离线可用。

## 交付物
- `tarot.html`：自包含单文件（浏览器直接打开即用，手机友好，底部三 Tab）。
- `src/`：模块化源码（模板 + 按页拆分 CSS/JS + 塔罗数据）。
- `_tools/verify.ps1`：一键构建 + 语法检查 + 无头回归（14 项自检全 PASS）。

## 功能清单
- 今日之牌：轻点牌背抽牌 → 翻转展示 正/逆位、总览、关键词、六维解读（事业/感情/财运/健康/人际/心灵）；每日一抽持久化，可覆盖重抽。
- 图鉴：78 张牌按大阿卡纳/四花色分组，支持搜索，星标已学习。
- 牌义详情：正位/逆位含义 + 关键词 + 牌面描述；轻触牌面切换正逆位视觉；已学习开关；无限条备注（500 字上限，可编辑/删除）。
- 我的：学习进度条、已学习列表、导出/导入 JSON 备份、重置数据、关于与更新记录。

## 数据内容
- 大阿卡纳 22 张：逐张 curated 正逆位摘要/关键词/六维今日解读/牌面描述。
- 小阿卡纳 56 张：逐张正逆位摘要/关键词/描述；六维今日解读由“花色×维度×正逆位 + 数字/宫廷收尾”模板生成。

- 构建：`node _tools\build.js`
- 验证：`powershell -NoProfile -ExecutionPolicy Bypass -File _tools\verify.ps1`
- 打开预览：直接双击 `tarot.html`，或 `?page=glossary|detail&card=m00|me|today` 直达页面。
